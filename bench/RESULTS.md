# Benchmark

What the gate and its mutation command catch, measured on 64 small projects: 32 fake changes an agent could make to get a green suite, and for each one its honest twin, the right version of the same change (32). Generated by `node bench/run`; CI runs it on every pull request and fails when anything below the header lines differs.

## Summary

| Cases | Tests only | Gate | Gate + mutants |
| --- | --- | --- | --- |
| Fakes the tool claims to catch (25) | 1 of 25 caught (1 did not run) | 20 of 25 caught | 25 of 25 caught |
| Fakes the tool does not claim to catch (7) | 0 of 7 caught (1 did not run) | 0 of 7 caught | 0 of 7 caught (2 did not run) |
| All fakes (32) | 1 of 32 caught (2 did not run) | 20 of 32 caught | 25 of 32 caught (2 did not run) |
| Honest twins (32) | 0 false alarms in 32 (1 did not run) | 0 false alarms in 32 | 1 false alarm in 32 (2 did not run) |

Tests only: the project's test command on the change (the tree it leaves, or a checkout of the commit a worktree left), judged by its exit code, as CI judges it. Gate: the gate's hooks as Claude Code runs them (the prompt, the change, the Stop). Gate + mutants: the gate, and when it lets the turn end, the mutation command on the change. A red fake is caught; a red honest case is a false alarm. "Did not run" is never counted as caught.
